# 星际留言服务

作品集的独立留言后台：Vinext / Cloudflare Worker + D1。前台仍部署在原来的 Surge 网址，静态页面本身不保存公开留言。

## 本地维护

需要 Node.js 22.13 或以上版本。进入本目录，运行 `npm run install:ci` 安装锁定版本，再运行 `npm run dev`；本地开发入口默认为 `http://127.0.0.1:5173/`。`npm run build` 生成 Worker 构建。作品集根目录的 Python 构建不安装或发布此后台。

`db/schema.ts` 是表结构；修改后运行 `npm run db:generate`，审阅并提交 `drizzle/` 中生成的 SQL 及迁移记录。部署时按迁移顺序应用到目标 D1；不要在处理访客请求时建表。现有留言迁移到新数据库前需先导出并备份数据，源码仓库不会携带线上评论或访客凭据。

## 部署与换地址

`.openai/hosting.json` 中的项目标识是公开部署元数据，不是访问令牌。维护原服务时保留标识及 `DB` 绑定；另行部署时使用目标平台正式创建的项目标识与 D1 数据库，完成构建、迁移和公开访问设置。不要提交平台登录凭据、`.env*`、`.dev.vars*`、`.wrangler/`、`.sites-runtime/` 或本地数据库。

作品集根目录 `guestbook.config.json` 的 `apiBase` 指向已部署后台的 HTTPS 根地址。换地址后重建前台。允许访问的前台域名在 `lib/guestbook-server.ts` 的 `ORIGINS` 中维护；更换前台域名时同步调整并重新发布后台。上线前从未登录浏览器验证公开读写及跨域请求。

## 访客交互

无需 GitHub 或其他账号。服务器签发随机的本机匿名身份，数据库仅保存令牌摘要；前台在本机保存该身份，昵称和所选十二星座随评论公开显示。清除浏览器数据后将失去原身份的删除权限，昵称不代表经过验证的真实身份。

API 包括匿名身份创建/更新、公开分页留言、回复、点赞切换及作者软删除；回复通过 `parentId` 关联。正文按纯文本处理，限制长度与发布频率。`@昵称` 是站内文字提及，不发送邮件或跨平台通知。线上数据与源码分开保存。
